# TickHappens

A free, open-source bullet heaven with 16-bit pixel art, dynamic lighting, and planned online co-op for 2–4 players. The longer a run lasts, the tougher it gets. Time statues push the clock forward.

**In development.** The visual benchmark and local asset pipeline are available now. The playable prototype, launcher, and in-game Workshop are on the roadmap.

[Try the visual benchmark](https://github.com/Tick-Happens-Team/Game#run-the-visual-benchmark) · [View the roadmap](https://github.com/Tick-Happens-Team/Game/blob/dev/ROADMAP.md)

## Repositories

- [Game](https://github.com/Tick-Happens-Team/Game) — C# engine, visual benchmark, AssetTool, and development docs. MIT.
- [Assets](https://github.com/Tick-Happens-Team/Assets) — Pixel art, procedural sprite recipes, and [atlas releases](https://github.com/Tick-Happens-Team/Assets/releases). Original assets are CC BY 4.0.
- [Mods](https://github.com/Tick-Happens-Team/Mods) — Community mod catalog and [contribution guide](https://github.com/Tick-Happens-Team/Mods/blob/main/CONTRIBUTING.md). Catalog tooling is MIT. Mods and third-party content carry their own licenses.
